# Smart Buyer: Best Deal Finder

A Grade 8 Financial Literacy PBL app for comparing unit prices, decoding promotions, scanning marketing tactics, and evaluating purchase value.

## Run locally

Open `index.html` in a browser. Installable PWA and offline caching work when hosted on HTTPS (or localhost).

## Files

- `styles.css` - responsive dark-mode interface
- `app.js` - calculator interactions and PWA registration
- `manifest.json` - install metadata
- `service-worker.js` - app-shell caching
- `icon.svg` - app icon
